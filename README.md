## ⚡ 핵심 경기 운영 및 결과 업로드 가이드

1. **대진에서 경기 불러오기 및 부문 선택 (`📅 대진에서 불러오기` · `남자/여자` · `초등/중등/고등`)**:
   - 새 경기(`🆕 새 경기`) 또는 전체 리셋(`⚠️ 전체 리셋`) 직후 조작 화면 중앙 상단에 대진표 불러오기 및 부문 선택 창이 표시됩니다.
   - **풀리그 경기 선택**: 부문(`gender`, `level`)과 `HOME`/`AWAY` 학교명이 대진표 표기 그대로 자동 입력됩니다.
   - **결승 경기 선택**: 해당 부문의 학교 목록(풀리그 항목에서 자동 추출) 드롭다운으로 `HOME`/`AWAY` 학교를 선택할 수 있습니다.
   - **직접 입력**: 기존 방식대로 부문을 고르고 학교명을 직접 입력할 수 있습니다 (인터넷 오프라인 시 `localStorage` 저장 대진표 사용).
   - 부문을 확정하기 전에는 타이머 시작과 득점 조작이 잠기며, 상단 바의 현재 부문 배지(예: `남자 초등부`)를 클릭해 언제든 변경할 수 있습니다.
2. **경기 기록 저장 및 결과 업로드 일원화 (`💾 경기 기록 저장` / `🆕 새 경기`)**:
   - 하단의 `💾 경기 기록 저장 및 로그 다운로드` 버튼을 누르면 서식 리포트/엑셀/CSV 다운로드와 함께, 설정된 업로드 주소로 해당 경기 결과 1건(`POST {업로드 주소}/matches`, `Authorization: Bearer {키}`, `schemaVersion: 1`, `division`, `scheduleNo`, `stage` 포함)이 자동 업로드됩니다.
   - `HOME`/`AWAY` 학교명이 비어 있으면 업로드하지 않고 `"학교명을 입력하세요"` 안내를 표시합니다.
   - 이 PC에서 저장한 대진 경기는 목록에 `"저장됨"`으로 표시됩니다.
3. **송출 전용 전광판 (`📺 송출화면 분리` / `W`)**:
   - 조작 화면에서 선수 명단을 켜 두더라도 송출 화면(`#broadcast`)에서는 선수 명단을 항상 숨기고 메인 점수판을 확대 상태로 유지합니다.

## ⌨️ 키보드 단축키 (운영 콘솔)

| 단축키 | 기능 설명 |
| :--- | :--- |
| **`Space`** | 메인 경기 타이머 시작 / 정지 |
| **`B`** | 경기장 전자 버저(Buzzer) 즉시 취명 |
| **`Q` / `A`** | HOME 팀 점수 +1 / -1 |
| **`P` / `L`** | AWAY 팀 점수 +1 / -1 |
| **`T`** | 작전 타임(30초) 시작 / 정지 |
| **`M`** | **선수명단 표시 / 숨김 (ON/OFF) 토글 (조작 화면 전용)** |
| **`W`** | **프로젝터/대형 화면용 클린 송출화면 새 창 열기 / 닫기** |
| **`F11`** | 경기장 전광판 전체화면 토글 |
| **`Esc`** | 일반 팝업 창 닫기 / 전체화면 해제 (부문 선택 창은 `확인`으로만 닫힘) |
