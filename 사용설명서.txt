[핵심 경기 운영 가이드]
--------------------------------------------------------------------
1. 대진에서 경기 불러오기 및 경기 부문 선택 (남자/여자 · 초등/중등/고등)
  - [🆕 새 경기] 또는 [⚠️ 전체 리셋] 직후 조작 화면 중앙 상단에 부문 선택 창이 표시됩니다.
  - 상단 [📅 대진에서 불러오기] 목록에서 풀리그 경기를 고르면 부문과 HOME/AWAY 학교명이 자동 입력됩니다.
  - 결승 경기를 고르면 해당 부문의 학교 목록 드롭다운에서 HOME/AWAY 학교를 선택할 수 있습니다.
  - [직접 입력]을 선택하면 기존 방식대로 부문과 학교명을 직접 지정할 수 있습니다.
  - 조작 화면 상단 배지(예: "남자 초등부")를 클릭해 언제든 변경할 수 있습니다.

2. 경기 기록 저장 및 서버 업로드 일원화
  - [💾 경기 기록 저장 및 로그 다운로드] 또는 [🆕 새 경기] 클릭 시 해당 경기 결과 1건
    (division, scheduleNo, stage 포함)이 POST {업로드 주소}/matches 로 업로드됩니다.
  - HOME/AWAY 학교명이 비어 있으면 업로드하지 않고 "학교명을 입력하세요" 안내가 표시됩니다.
  - 이 PC에서 저장한 대진 경기는 대진 목록에 "저장됨"으로 표시됩니다.

3. 송출 화면 선수 명단 자동 숨김
  - 조작 화면에서 선수 명단이 ON이어도 송출 화면(#broadcast)에서는 항상 명단을 숨기고
    메인 점수판을 확대 상태로 유지합니다.

[키보드 단축키]
--------------------------------------------------------------------
  - Space : 메인 경기 타이머 시작 / 일시정지
  - B     : 전자 버저(Buzzer) 즉시 취명
  - Q / A : HOME 팀 점수 +1 / -1
  - P / L : AWAY 팀 점수 +1 / -1
  - T     : 작전 타임(30초) 시작 / 정지
  - M     : 선수명단 표시 / 숨김 (ON/OFF) 토글 (조작 화면 전용)
  - W     : 프로젝터/대형 화면용 클린 송출화면 새 창 열기 / 닫기
  - F11   : 전광판 전체화면 토글
  - Esc   : 일반 팝업 닫기 / 전체화면 해제
